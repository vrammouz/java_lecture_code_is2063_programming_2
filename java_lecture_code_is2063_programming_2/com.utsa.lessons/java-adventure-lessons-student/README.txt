JAVA ADVENTURE LESSONS — STUDENT EDITION
========================================

Audience: students who completed Programming I in Python.
Tested target: JDK 21.

RUN A DEMO
  cd demos/C02_Fundamentals
  javac Step1_Room.java
  java Step1_Room

Run file-reading examples from the directory containing their .txt data.

LEARNING SEQUENCE
  C01 Toolchain                 C07 Collections and arrays
  C02 Fundamentals             C08 References and equality
  C03 Decisions                C09 Text parsing
  C04 Loops and files          C10 Polymorphism
  C05 Methods                  C11 Exceptions
  C06 Classes

Two exercises are intentionally flawed so you can diagnose and repair them:
  labs/C03_Decisions/Lab2_Starter.java
  labs/C08_References/Lab8_Starter.java

For deliberate-failure activities, predict the outcome before running,
identify the relevant line, then explain the repair in your own words.

USE THE P-E-C-E CYCLE
  Predict: write what you expect before running.
  Evidence: capture the output, compiler diagnostic, or stack trace.
  Claim: explain the result using a Java rule, not just what happened.
  Extend: change one condition or input and predict again.

See exercises.txt for questions accompanying every chapter.
